# 🛒 CampusCart

CampusCart is a full-stack marketplace designed exclusively for college students to buy and sell hostel essentials such as books, calculators, cycles, electronics, furniture, and other daily-use items.

The platform provides secure user authentication, image uploads, listing management, and review functionality to create a smooth buying and selling experience within a college campus.

---

## 🚀 Features

- User Registration & Login
- Secure Authentication using Passport.js
- Create, Edit and Delete Listings
- Upload Product Images using Cloudinary
- Add Reviews and Ratings
- Flash Messages
- Session Management
- Form Validation using Joi
- Responsive UI
- RESTful Routing
